# Структура проекта — HTML верстка

> Для передачи программисту (Laravel). Mobile-first, тёмная тема.
> Всего: **45 экранов**, все готовы.

## Маппинг на Laravel Routes

| Папка верстки | Laravel Route Group | Middleware | Кол-во |
|---|---|---|---|
| `pages/auth/` | `Route::prefix('auth')` | `guest` | 7 |
| `pages/public/` | Корневые роуты `/` | — | 3 |
| `pages/dashboard/` | `Route::prefix('dashboard')` | `auth` | 6 |
| `pages/teams/` | `Route::prefix('teams')` | `auth` (часть — публичная) | 4 |
| `pages/tournaments/` | `Route::prefix('tournaments')` | `auth` (часть — публичная) | 3 |
| `pages/matches/` | `Route::prefix('matches')` | `auth` | 2 |
| `pages/stats/` | `Route::prefix('stats')` | — | 2 |
| `pages/admin/super/` | `Route::prefix('admin')` | `auth`, `role:superadmin` | 7 |
| `pages/admin/tournament/` | `Route::prefix('admin/tournament')` | `auth`, `role:tournament_admin` | 5 |
| `pages/errors/` | Обработчики исключений | — | 3 |
| `pages/components/` | — (только для разработки) | — | 3 |
| **Итого** | | | **45** |

## Навигация (Bottom Nav)

### Публичная зона (неавторизованный)
Главная → Турниры → Команды → Рейтинги → Войти

### Авторизованный пользователь
Главная → Турниры → Команда → Профиль

### Суперадмин
Панель → Юзеры → Оплаты → Список → Настройки

### Админ турнира
Турниры → Управление → Telegram

## Общие компоненты (style.css)

| Компонент | CSS класс | Описание |
|---|---|---|
| Хедер | `.site-header` | Sticky, blur-backdrop, логотип + действия |
| Bottom Nav | `.bottom-nav` | Фиксированная навигация снизу (скрыта на десктопе) |
| Карточка | `.card` | Фон, рамка, скругления, тень |
| Auth-страница | `.auth-page`, `.auth-content` | Fullscreen мобилка, карточка на десктопе |
| Кнопки | `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-sm` | Разные размеры и стили |
| Инпуты | `.form-input`, `.form-label`, `.form-group` | Тёмные поля ввода |
| Бейджи | `.badge-active`, `.badge-upcoming`, `.badge-finished` | Статусы |
| Вкладки | `.tabs`, `.tab-btn` | Горизонтальные табы |
| Фильтры | `.filters`, `.filter-btn` | Пилюли-фильтры |
| Таблицы | `.table-wrapper` | Горизонтальный скролл на мобилке |
| Тосты | `.toast` | Всплывающие уведомления |
| Модалки | Демо в `components/modal.html` | Overlay + карточка |
| Скелетоны | Демо в `components/skeleton.html` | Shimmer-анимация |

## Стиль

- **Mobile-first**: base 375px, адаптив 480px+, 768px+
- **Тема**: тёмная (#060d1b deep, #0b1628 base, #111e35 cards)
- **Акценты**: зелёный (#22c55e) основной, синий (#3b82f6), жёлтый (#f59e0b), красный (#ef4444)
- **Шрифт**: Manrope (Google Fonts)
- **CSS переменные**: все цвета, отступы, радиусы в `:root`
- **Иконки**: inline SVG (без внешних библиотек)
